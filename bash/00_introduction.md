# Introduction to Bash/Linux

## What is Bash?

Bash (Bourne Again SHell) is a command-line interpreter for Unix-based operating systems. It's a powerful tool that allows you to interact with your computer through text commands instead of a graphical interface.

## What is a Shell?

A shell is a program that acts as an interface between the user and the operating system. It takes commands from the keyboard and passes them to the operating system to execute.

## What is a Terminal?

A terminal (or terminal emulator) is an application that provides a text-based interface to interact with a shell. Think of it as a window where you type commands for the shell to execute.

## Basic Shell Commands

Here are some essential commands you'll use frequently:

- `echo [text]` - Displays text to the terminal
- `clear` - Clears the terminal screen
- `history` - Shows command history
- `man [command]` - Displays manual page for a command
- `whoami` - Shows your current username
- `date` - Shows current date and time

These commands form the foundation of your journey with the terminal. As you practice using them, you'll become more comfortable navigating and managing your system through the command line.
